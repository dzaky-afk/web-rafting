# SA Adventure - Rafting Cisadane Bogor

Website resmi landing page penyedia layanan arung jeram (rafting), outbound gathering, paintball, penginapan villa, dan catering di Sungai Cisadane Caringin, Bogor.

🌐 **Live Demo / URL**: [https://saadventure.com](https://saadventure.com)  
📍 **Lokasi Basecamp**: Jl. Raya Bogor - Sukabumi Desa No.1, RT.02/RW.03, Caringin, Kec. Caringin, Kabupaten Bogor, Jawa Barat 16730  

---

## 🌊 Fitur Utama Website

- **Hero & Interactive Overview**: Informasi jalur 7 KM & 11 KM, grade jeram (Grade II–III+), instruktur berlisensi BNSP, dan standar keamanan internasional.
- **Katalog Paket & Booking Calculator**: Kalkulator estimasi biaya otomatis dengan diskon bertingkat rombongan, add-on dokumentasi & akomodasi.
- **Pilihan Paket Lengkap**:
  - Paket Rafting Reguler & Hemat
  - Paket Outbound Gathering & Team Building
  - Paket Paintball & Flying Fox
- **Akomodasi & Catering**: Galeri villa (Zanara & Mawar) dan menu catering khas Sunda dengan filter kategori interaktif.
- **Galeri Foto & Video**: Dokumentasi keseruan rafting di Cisadane dengan modal lightbox responsif.
- **Peta Lokasi & Kontak Cepat**: Integrasi Google Maps, jam operasional, dan tombol WhatsApp multi-admin (Utama & Cadangan).
- **Optimasi SEO & Performa**: Schema JSON-LD lengkap (LocalBusiness, FAQ, Breadcrumb, Catalog Offer), metadata Open Graph, serta fast loading Next.js.

## 🛠️ Teknologi yang Digunakan

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Outfit & Plus Jakarta Sans via `next/font/google`

## 🚀 Menjalankan Project Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/dzaky-afk/web-rafting.git
   cd web-rafting
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

4. **Build untuk production:**
   ```bash
   npm run build
   npm run start
   ```
